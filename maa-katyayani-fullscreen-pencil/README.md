# Maa Katyayani — Fullscreen Pencil Reveal

- Uses your supplied reference image.
- Full-window canvas layout with `object-fit: contain` sizing, so the complete image remains visible without cropping.
- Automatic 20-second reveal with pencil cursor moving bottom-to-top and a late colour reveal.
- Files: `index.html`, `style.css`, `script.js`, `maa-katyayani-reference.jpg`.

## Run
Extract the ZIP, open the folder in Cursor, and open `index.html` in a browser or use Live Server. Press Replay to restart.

Note: the effect uses image-edge-derived pencil strokes and a colour blend to simulate drawing. It does not manually trace every contour as an illustrator would.
