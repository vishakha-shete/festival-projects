# Gannu Bappa — The Arrival

A single cinematic React/Vite scene:

1. Golden dots form a glowing Earth.
2. The dots travel from Earth toward the Moon.
3. The Moon fades.
4. The supplied Gannu Bappa image arrives and grows into view.
5. Flowers begin blooming/falling around Bappa.
6. Fireworks and sparkles celebrate the arrival.
7. The 15-second sequence loops.

Run:
npm install
npm run dev
