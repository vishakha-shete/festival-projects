# Maa Skandamata — Navratri Day 5

A small devotional creative-coding project built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure
- `style.css` — layout, colors, and animations
- `script.js` — blessing button interaction
- `maa-skandamata.jpg` — supplied reference artwork

## Run locally
Open `index.html` in your browser, or open this folder in Cursor and use the Live Server extension.

The Google Fonts import requires an internet connection; the page still works without it.
