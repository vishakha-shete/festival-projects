# 🥣 Gopalkala 2K26

An interactive one-page Gopalkala experience built with React + Vite.

## Features
- Drag ingredients into the traditional matki
- Tap ingredients on mobile
- Poha, chana dal, cucumber, apple, pomegranate, corn, cut banana, coconut, coriander, salt and lemon
- Interactive circular mixing gesture
- Progress tracking and animated ingredients
- Festive completion screen

## Run
```bash
npm install
npm run dev
```
