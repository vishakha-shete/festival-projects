# Navratri Day 7 — Maa Kalaratri Cosmic Reveal

A laptop-first devotional reveal built with HTML, CSS and vanilla JavaScript, using the supplied Maa Kalaratri image.

## Run
1. Extract the ZIP.
2. Open this folder in Cursor.
3. Open `index.html` with Live Server (or open the file directly in a browser).
4. Press F11 for browser full-screen and click **Replay the Reveal** to record again.

## Effects
- Responsive artwork sizing with `object-fit: contain` so the full image stays visible.
- Bottom-to-top animated image reveal with a moving golden light edge.
- Cosmic particles, rotating halo, lightning flashes, progress bar and replay control.
- Nine-second automatic reveal; no npm installation required.
